# Examples

Runnable snippets demonstrating common `@gnapex/sdk` usage patterns. These are illustrative code samples, not full standalone projects — copy the relevant file(s) into your app.

| Example                                     | Demonstrates                                                                                                                                           |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`nextjs-app-router/`](./nextjs-app-router) | `NexusProvider` setup in an App Router `layout.tsx`, server-side `getPage` fetch, client-side analytics + auth hooks, privacy-conscious consent gating |
| [`node-script/`](./node-script)             | Using the core client (no React) from a plain Node.js script — e.g. a build step or cron job that pulls content                                        |

See the main [README](../README.md) for the full API reference these examples draw from.
